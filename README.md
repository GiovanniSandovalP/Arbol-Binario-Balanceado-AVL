# Gestión de Empleados - Árbol AVL

Proyecto escolar en Java (NetBeans Swing) para administrar empleados utilizando un **Árbol Binario Balanceado (AVL)**.

## ⚙️ Funcionalidades

* **Operaciones:** Agregar, buscar, eliminar y vaciar árbol.
* **Autobalanceo:** Aplicación de rotaciones (simples y dobles) tras insertar o eliminar.
* **Recorridos:** Inorden, Preorden y Postorden.
* **Métricas:** Cálculo de profundidad y amplitud.

## 📁 Estructura

* `Empleado`: Datos del trabajador (ID, nombre, puesto, departamento, salario).
* `NodoAVL`: Nodo con punteros y control de altura.
* `ArbolAVL`: Lógica de ordenamiento y autobalanceo.
* `InterfazGrafica`: Interfaz Swing para manipular el árbol.
